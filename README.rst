=======
QSW_MPI
=======

Overview
--------

QSW_MPI simulates Markovian open quantum systems using MPI. It provides two
classes for quantum stochastic walks on graphs, ``LQSW`` for walks with local
Lindblad operators and ``GQSW`` for walks with global Lindblad operators.
A third class, ``GKSL``, solves the Lindblad master equation for a
user-supplied sparse Hamiltonian and a sequence of Lindblad operators.

If you use QSW_MPI in your research, please cite the paper associated with its first release:

.. code-block:: bibtex

    @article{MatwiejewWang2021,
      author  = {Matwiejew, Edric and Wang, Jingbo},
      title   = {{QSW\_MPI}: A framework for parallel simulation of quantum stochastic walks},
      journal = {Computer Physics Communications},
      volume  = {260},
      pages   = {107724},
      year    = {2021},
      doi     = {10.1016/j.cpc.2020.107724}
    }

Requirements
------------

Building from source requires Python 3.9 or later, C and Fortran compilers,
and an MPI implementation with Fortran development files. The build
uses CMake 3.20 or later. 

Installation
------------

From the repository root, build and install QSW_MPI into the active Python
environment with pip.

.. code-block:: console

    python -m pip install .

The ``visualisation`` extra installs Matplotlib and NetworkX for the examples.

OpenMP threading is off by default. To enable it, pass the CMake option to pip.

.. code-block:: console

    python -m pip install . -Ccmake.define.QSW_OPENMP=ON

Serial output uses h5py. Parallel output requires the native writer, which
CMake builds automatically when it finds parallel HDF5 with Fortran support.
Set ``-Ccmake.define.QSW_PARALLEL_IO=ON`` to require it, or use ``OFF`` to
omit it. Set ``HDF5_ROOT`` if the parallel installation is in a custom location.
To select an MPI compiler wrapper, set ``FC`` before building (for example,
``FC=ftn`` on Cray systems).

For a debug build, including runtime checks with GNU Fortran, run
``python -m pip install . -Ccmake.build-type=Debug``.
To create a source archive and build a wheel from it in ``dist/``, run
``python -m pip install build`` followed by ``python -m build``.

Quick start
-----------

From the repository root::

    python -m pip install '.[visualisation]'
    mpiexec -n 4 python examples/4_gksl_superradiance.py


Documentation
-------------

To build the HTML documentation from the repository root::

    python -m pip install -r docs/requirements.txt
    make -C docs html

QSW_MPI Package Contents Overview
---------------------------------

Program Files
^^^^^^^^^^^^^

* README.rst - QSW_MPI basic information.
* LICENSE - QSW_MPI license.
* pyproject.toml - Package metadata, dependencies and scikit-build-core configuration.
* CMakeLists.txt - Builds and installs the Fortran extensions.

* src/qsw_mpi/

  * __init__.py - Python package initialization.
  * MPI.py - Parallel operations, quantum stochastic walk system creation and propagation.
  * operators.py - Creation of local quantum stochastic walk operators.
  * parallel_io.py - MPI-enabled output of results.

* native/

  * parallel_io.f90 and fHDF5.pyf - Native parallel HDF5 writer and its Python interface.
  * foperators.f90 - Source code for foperators shared object library.
  * foperators.pyf - Defines the python interface generated by f2py for the foperators shared object library.
  * fMPI.f90 - Source code for fMPI shared object library.
  * fMPI.pyf - Defines the python interface generated by f2py for the fMPI shared object library.
  * iso_precisions.f90 - Defines fortran precision types.
  * sparse.f90 - Sparse data representation and parallel BLAS operations.
  * one_norms.f90 - Parallel 1-norm estimation.
  * expm.f90 - Parallel calculation of the action of the matrix exponential on a complex vector.
  * operators.f90 - Creation of local and distributed quantum stochastic walk operators.

Other Files
^^^^^^^^^^^

* examples/ - MPI examples of quantum stochastic walks and Dicke superradiance.

* docs/

  * Makefile - Documentation make script for Unix-like systems.
  * make.bat - Documentation build script for Windows systems.
  * requirements.txt - Dependencies for the Sphinx documentation build.
  * source/ - Documentation source files and images.
